# 🎮 OyunPortal.org

## 🎯 Məqsəd və İcmal
Oyun valyutaları (Steam, PUBG Mobile UC, Valorant VP, Free Fire və s.) və rəqəmsal e-pin kodlarının satışı üçün müasir e-ticarət platforması.

## 🛠️ Texnoloji Qala (Stack)
- **Frontend & Backend**: Next.js (App Router), TypeScript, Tailwind CSS
- **Verilənlər Bazası & ORM**: PostgreSQL, Prisma
- **Ödəniş & İstifadəçi**: Daxili Wallet sistemi, Sürətli balans artırma, Avtomatlaşdırılmış pin çatdırılması
