# 🎯 Mərkəzləşdirilmiş İş Axtarış Kriteriyaları (AdemOS)

Bu sənəd Adem-in `User-Profile.md` və CV məlumatlarına əsaslanan bütün hədəf iş kateqoriyalarını, açar sözlərini və qiymətləndirmə standartını təyin edir.

---

## 🏛️ 8 Əsas İş Kateqoriyası və Hədəf Vəzifələr

### 1. 💻 Software Development
- Python Developer, Django Developer, Backend Developer
- Frontend Developer, Next.js Developer, TypeScript Developer
- Full-Stack Developer, Software Engineer, Web Developer, API Developer

### 2. 🤖 AI / Machine Learning
- AI Engineer, AI Developer, AI Software Engineer
- Machine Learning Engineer, Deep Learning Engineer, Applied AI Engineer, AI Research Engineer
- Computer Vision Engineer, NLP Engineer, Generative AI Engineer, LLM Engineer
- AI Agent Engineer, AI Solutions Engineer, AI Integration Engineer
- AI Platform Engineer, AI Infrastructure Engineer, MLOps Engineer, ML Platform Engineer
- Data Scientist, Data Engineer, Data Analyst

### 3. ⚡ LLM / Generative AI / Automation
- LLM Developer, LLM Application Engineer, Generative AI Developer
- Prompt Engineer, RAG Engineer, AI Automation Engineer, AI Agent Developer
- Conversational AI Engineer, Chatbot Developer, AI API Integration Developer, AI Workflow Engineer

### 4. 📈 AI Product / Business
- AI Product Engineer, AI Product Manager, AI Solutions Architect
- AI Consultant, AI Technical Consultant, AI Implementation Specialist
- AI Operations Specialist, AI Project Manager

### 5. ☁️ DevOps / Cloud / Infrastructure
- DevOps Engineer, Cloud Engineer, Infrastructure Engineer
- Site Reliability Engineer (SRE), Platform Engineer, Linux Administrator, Cloud Support, Server Administrator

### 6. 🖥️ System Administration
- System Administrator, Junior System Administrator, IT Administrator
- Network Administrator, Network Support, NOC Technician, IT Specialist, IT Technician

### 7. 🛠️ IT Support / Help Desk
- IT Support, Help Desk, Technical Support
- Desktop Support, Desktop Technician, IT Support Specialist, Technical Support Specialist, Field IT Technician

### 8. 🖨️ Praktiki IT / Ofis Texnikası
- Kompüterlərin yığılması və texniki xidməti, Windows quraşdırılması və sazlanması
- Proqram və driver quraşdırılması, Printer/Skaner şəbəkə problemlərinin həlli
- LAN / Wi-Fi şəbəkə quraşdırılması, Router / Switch konfiqurasiyası
- Təhlükəsizlik kamera sistemləri (CCTV), Antivirus və backup həlləri
- İstifadəçi hesablarının idarəsi, Active Directory və şirkət kompüterlərinə ümumi texniki dəstək

## 🔍 Axtarış Qaydaları & Açar Söz Matrisi
Axtarış yalnız vəzifə adına (Job Title) görə deyil, elanın gövdəsindəki bu açar sözlərə əsasən aparılır:
- `Python`, `Django`, `Next.js`, `TypeScript`, `React`, `PostgreSQL`, `MySQL`, `Redis`, `Celery`, `REST API`
- `AI`, `LLM`, `GPT`, `Generative AI`, `RAG`, `AI Agents`, `Machine Learning`, `MLOps`, `OpenRouter`
- `Linux`, `VPS`, `Nginx`, `Git`, `Cloudflare`, `DevOps`
- `Windows`, `Active Directory`, `IT Support`, `Help Desk`, `System Administration`, `Network`, `NOC`, `Desktop Support`, `Printer`, `LAN/Wi-Fi`

## 📋 Qiymətləndirmə Şablonu (Standart)
Hər bir tapılmış elan bu formatda analiz olunur:
- **Şirkət & Vəzifə**: [Şirkət Adı] — [Vəzifə]
- **Məkan / Model**: [Bakı / Remote / Hibrid / Xarici Remote]
- **Maaş**: [Göstərilən məbləğ və ya "Məlum deyil"]
- **Birbaşa Vakansiya Linki**: [Birbaşa elanın linki - əsas domen deyil]
- **🎯 Uyğunluq Skoru**: [0–100%]
- **Status**: [🟢 Tam uyğun / 🟡 Qismən uyğun / 🔴 Çatışmır]
- **Tələblər**: [Vakansiyadakı əsas texnoloji və təcrübə tələbləri]
- **💪 Mənim Güclü Tərəflərim**: [Adem-in real profili və CV-si ilə üst-üstə düşən hissələr]
- **⚠️ Çatışmayan Bacarıqlar**: [Əlavə öyrənilməli və ya təcrübə çatışmayan hissələr]
- **💡 "Sadə dildə bu iş nədir?"**: [İşin gündəlik real mahiyyətinin 1-2 cümləlik sadə izahı]
