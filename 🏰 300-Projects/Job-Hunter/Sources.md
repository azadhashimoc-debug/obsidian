# 🌐 İş Axtarış Mənbələri (Sources)

AdemOS Job Hunter sisteminin monitorinq etdiyi rəsmi mənbələr və birbaşa axtarış kanalları:

---

## 1. 🇦🇿 Azərbaycan Yerli İş Portalları
- **JobSearch.az** (`https://jobsearch.az`) — Əsas IT, Proqramlaşdırma, Sistem İnzibatçılığı və Mühəndislik vakansiyaları.
- **HelloJob.az** (`https://hellojob.az`) — Proqram təminatı, IT Support, Help Desk, Şəbəkə və Web vakansiyaları.
- **SmartJob.az** (`https://smartjob.az`) — Texniki xidmət, IT mütəxəssis və praktiki kompüter ustası elanları.
- **LinkedIn (Azerbaijan Tech)** (`https://linkedin.com/jobs`) — Bakı üzrə yerli və qlobal texnologiya şirkətlərinin elanları.

---

## 2. 🌍 Beynəlxalq Remote İş Platformaları
- **Arc.dev** (`https://arc.dev`) — Qlobal remote Python, Django, React və Next.js Developer vakansiyaları.
- **RemoteOK** (`https://remoteok.com`) — Dünya miqyasında Full-Stack, AI və DevOps uzaqdan işləri.
- **WeWorkRemotely** (`https://weworkremotely.com`) — Yoxlanılmış beynəlxalq proqram mühəndisliyi elanları.
- **ReactJobs.io** (`https://reactjobs.io`) — Frontend, Next.js və TypeScript ixtisaslaşmış elanlar.
- **4DayWeek.io** (`https://4dayweek.io`) — Çevik qrafikli qlobal proqramlaşdırma vakansiyaları.
