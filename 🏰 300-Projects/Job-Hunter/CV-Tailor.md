# ✍️ CV Tailor: Vakansiyaya Uyğun Fərdiləşdirmə Agenti

Bu modul hədəf vakansiyanın açar sözlərinə (ATS) və tələblərinə uyğun olaraq CV-də **hansı real layihələrin və təcrübələrin ön plana çıxarılmalı olduğunu** müəyyənləşdirir.

> ⚠️ **Prinsip**: Yalan məlumat və olmayan təcrübə qətiyyən əlavə edilmir. Yalnız mövcud layihələrin (Panelim, OyunPortal, Safmoto, Unity) ən uyğun tərəfləri vurğulanır. Mövcud CV avtomatik dəyişdirilmir; əvvəlcə təklif göstərilir və təsdiq gözlənilir.

---

## 🎯 Vakansiyalar üzrə Fərdiləşdirmə Taktikaları

### 1. AI & Python/Django Vakansiyaları üçün (Məs: Dapti, Rewire)
- **Önə Çıxarılacaq Layihə**: `Panelim.az / NovaPanel`
- **Vurğulanacaq Texniki Hissələr**:
  - Django + Celery/Redis ilə asinxron fon işlərinin idarə edilməsi.
  - PostgreSQL tranzaksiya təhlükəsizliyi və performans optimizasiyası.
  - AI sistemləri və LLM inteqrasiyaları ilə praktiki məhsul qurulması.
- **Summary Təklifi**: *"Python/Django və AI sistemləri üzrə ixtisaslaşmış, asinxron arxitekturalar və real məhsul inkişafı təcrübəsinə malik Full-Stack Developer."*

---

### 2. Next.js & Frontend Vakansiyaları üçün (Məs: Clopos, Arc.dev)
- **Önə Çıxarılacaq Layihə**: `OyunPortal.org` və `NovaPanel UI`
- **Vurğulanacaq Texniki Hissələr**:
  - Next.js (App Router), TypeScript, Server Components və SSR/ISR.
  - Tailwind CSS və müasir Dark/Glassmorphism dizayn sistemləri.
  - Yüksək sürətli frontend-backend API inteqrasiyası.
- **Summary Təklifi**: *"Next.js və TypeScript ilə yüksək performanslı, SEO-dostu və müasir UI/UX standartlarına cavab verən SaaS tətbiqləri quran Developer."*
