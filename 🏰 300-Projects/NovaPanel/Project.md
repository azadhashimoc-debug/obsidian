# 🚀 NovaPanel / Panelim.az

## 🎯 Məqsəd və İcmal
Azərbaycan bazarı üçün hazırlanmış dinamik, yüksək təhlükəsizlikli və avtomatlaşdırılmış SMM xidmət və idarəetmə platforması.

## 🛠️ Texnoloji Qala (Stack)
- **Backend**: Django (Python 3.12+), Celery, Redis
- **Verilənlər Bazası**: PostgreSQL (Production), SQLite (Lokal)
- **Təhlükəsizlik**: Cloudflare Turnstile, CSP, Rate Limiting, Nginx reverse-proxy
- **Marketinq**: Meta Ads (Winning Campaign), TikTok/Reels ssenariləri
